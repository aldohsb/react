Buatkan panduan  dan file lengkap proyek React di bawah ini, 
Judul : 

sertakan pembahasan pelajaran teknik react yang dibahas di atas, pembahasan level beginner, pakai bahasa awam.
proyek jangan terlalu rumit, yang simple saja, fokuskan pelajaran teknik yang disebutkan diatas
lengkapi code dengan banyak komentar untuk menjelaskan setiap baris code untuk belajar.

UI/UX standart profesional, designer grade.
Terapkan modular programming, dan setiap file di tulis di masing-masing artifact agar mudah di copy.
jangan gunakan syntax code yang sudah deprecated.
sertakan code bash touch mkdir untuk membuat struktur file lengkap semua file termasuk di root.
tidak usah pakai demo tampilan, tidak usah pakai README.MD,

kalau terlalu panjang bagi proyek menjadi beberapa part tapi setiap part bisa langsung di lihat hasilnya, agar segera bisa di fix  kalau ada error, kemudian lanjut dengan  part selanjutnya di chat berikutnya.
